# Rider questions

The current app uses guided lookups. Use these questions to demonstrate the two options or to evaluate a future natural-language interface.

| Rider question | Lookup and expected behaviour |
|---|---|
| Which routes serve STESEN BRT SETIA JAYA? | Search for the stop, confirm its ID and list the routes in the snapshot. |
| Does the Sunway Line serve this stop? | Confirm the stop and check its route list for B1000. |
| Which stop comes next on my trip? | Choose the trip ID and read the next row in numeric stop sequence. |
| Which TAMAN MUHIBBAH do you mean? | Display all matching names with stop IDs and ask the rider to select one. |
| Is my bus late right now? | Explain that the snapshot contains scheduled service. Refer the rider to the operator for live status. |
